# Polyvinyl chloride (PVC) ingestion has little impact on the gut microbiomes of mealworms

Rondinelli MA, Kaur S, Sunny JS & diCenzo GC. 2026. Polyvinyl chloride (PVC) ingestion has little impact on the gut microbiomes of mealworms. *Update upon submission*

This repository contains the scripts and input files required to repeat the analyses reported in the associated article.

## Linux

This folder contains the overall workflow (workflow.sh) and associated scripts required to repeat all analyses run in a bash environment, including read QC, metagenome assembly, binning, MAG taxonomic classification and clustering, phylogenetic reconstruction from the MAGs, and identification of proteins of interest.

## R

This folder contains the overall workflow for all statistical analyses presented in the manuscript (PVC_statistics.Rmd), as well as the required input files and an HTML file of the output.
